How vowels are written

A vowel never stands alone: each syllable block begins with a consonant, and if there is no consonant sound the silent letter ㅇ is used, as in 아 (a). Vowels go to the right of the consonant if they are vertical (ㅏ, ㅓ, ㅣ) and below it if they are horizontal (ㅗ, ㅜ, ㅡ).

Basic and combined

The ten basic vowels are ㅏ ㅑ ㅓ ㅕ ㅗ ㅛ ㅜ ㅠ ㅡ ㅣ. The others combine them: ㅐ and ㅔ, ㅒ and ㅖ, ㅘ ㅙ ㅚ, ㅝ ㅞ ㅟ and ㅢ. The "y" vowels (ㅑ ㅕ ㅛ ㅠ) add a short stroke to the basic ones. The Unicode names are the standard names of the letters.
