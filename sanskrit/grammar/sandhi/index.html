Sandhi: how sounds join

When two words or word-parts meet, the last sound of the first and the first sound of the second often blend into something new. This blending is सन्धि (sandhi), "joining". विद्या + आलयः becomes विद्यालयः; नमः + ते becomes नमस्ते.

Every language does this in speech: English "do not" becomes "don't". What is special about Sanskrit is that the blending is also written, and written strictly by rule. That is why a line of a shloka looks like one long word. To read it, you must undo the sandhi, a step called सन्धि-विच्छेद (sandhi-vichchheda). Hindi keeps hundreds of Sanskrit sandhi words, so you know many results already: हिमालय, सूर्योदय, इत्यादि, स्वागत, सज्जन.

There are three families: vowel sandhi (स्वर), consonant sandhi (व्यञ्जन) and visarga sandhi (विसर्ग).

Vowel sandhi

1. दीर्घ (dirgha): like vowels make one long vowel

RuleExampleResult
अ/आ + अ/आ = आविद्या + आलयःविद्यालयः
अ/आ + अ/आ = आहिम + आलयःहिमालयः
इ/ई + इ/ई = ईकवि + इन्द्रःकवीन्द्रः
उ/ऊ + उ/ऊ = ऊभानु + उदयःभानूदयः

2. गुण (guna): अ or आ + a different vowel

RuleExampleResult
अ/आ + इ/ई = एदेव + इन्द्रःदेवेन्द्रः
अ/आ + उ/ऊ = ओसूर्य + उदयःसूर्योदयः
अ/आ + उ/ऊ = ओमहा + उत्सवःमहोत्सवः
अ/आ + ऋ = अर्महा + ऋषिःमहर्षिः

3. वृद्धि (vriddhi): अ or आ + ए, ऐ, ओ, औ

RuleExampleResult
अ/आ + ए/ऐ = ऐसदा + एवसदैव
अ/आ + ए/ऐ = ऐएक + एकम्एकैकम्
अ/आ + ओ/औ = औमहा + औषधम्महौषधम्

4. यण् (yan): इ, उ, ऋ before a different vowel

RuleExampleResult
इ/ई + other vowel = य्इति + आदिइत्यादि
इ/ई + other vowel = य्यदि + अपियद्यपि
उ/ऊ + other vowel = व्सु + आगतम्स्वागतम्
ऋ + other vowel = र्पितृ + आज्ञापित्राज्ञा

5. अयादि (ayadi): ए, ऐ, ओ, औ before a vowel

RuleExampleResult
ए + vowel = अय्ने + अनम्नयनम्
ऐ + vowel = आय्नै + अकःनायकः
ओ + vowel = अव्पो + अनःपवनः
औ + vowel = आव्पौ + अकःपावकः

Consonant sandhi: two common cases

A hard consonant softens before a soft sound

ExampleResultWhat happened
जगत् + ईशःजगदीशःत् became द् before a vowel
सत् + जनःसज्जनःत् became ज् before ज
वाक् + ईशःवागीशःक् became ग् before a vowel
उत् + नतिःउन्नतिःत् became न् before न

Visarga sandhi: three common cases

What the visarga (ः) turns into

ExampleResultWhat happened
नमः + तेनमस्तेः became स् before त
मनः + रथःमनोरथःअः became ओ before a soft consonant
सः + अपिसोऽपिअः + अ became ओ, and the अ dropped (marked ऽ)
निः + चयःनिश्चयःः became श् before च

Undoing sandhi in a shloka

Take the first line of Gita 2.47: कर्मण्येवाधिकारस्ते. It is four words run together. Working backwards: कर्मणि + एव gave कर्मण्येव (yan sandhi: इ before ए became य्); एव + अधिकारः gave एवाधिकारः (dirgha: अ + अ = आ); and अधिकारः + ते gave अधिकारस्ते (visarga became स् before त). So the words are कर्मणि एव अधिकारः ते: "in action alone [is] the right of you".

How to learn sandhi

  1. Start with the five vowel sandhis; they account for most of what you will meet.
  2. For each rule, learn one example you already know from Hindi: विद्यालय, सूर्योदय, सदैव, इत्यादि, नयन.
  3. Practise in both directions: join given pairs, and split given words.
  4. When you read a shloka, mark every ऽ, every long vowel in the middle of a compound and every य् or व् before a vowel: these are the usual signs of a sandhi.

This page gives the main rules in their simplest form. Each rule has exceptions and finer points, which are set out in full in any standard Sanskrit grammar.
