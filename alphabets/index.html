What you will find here

Each script page shows its letters in a chart, with the name of each letter from the Unicode Character Database and, where we have a source, a Latin equivalent. Below the chart is a quiz that shows a letter and asks for its name, and a short guide to learning the script. The two guides explain the kinds of scripts (alphabet, abjad, abugida, syllabary) and give a seven day plan.

How the charts are made

The letters are not typed by hand. We chose which letters make up the basic set of each script, and the program reads each letter's official name from the Unicode data, so that a mistake in a letter or its name is unlikely. What the charts cannot show is how a letter is written (its stroke order) or how it sounds in a real voice, so use them together with a teacher, a textbook or a speaker.

Questions

Which script is the easiest to learn?

The ones that are written as they are said, such as Hangul, hiragana, Georgian and the Indian scripts, can be read aloud after a few days. See the guide on the kinds of scripts.

Why is Chinese not here?

Chinese is written with thousands of characters, not a short set of letters, so a chart of the basic letters does not apply.
