Thai: letters, names and quiz

44 symbols of the Thai script (ไทย), used for Thai.

Thai is the script of Thailand. It is written from left to right with no spaces between words, only between phrases. It is an abugida with 44 consonant letters, and vowels written before, after, above and below the consonant.

Thai has five tones, and the tone of a syllable depends on the class of the consonant letter, the vowel length, the ending and the tone mark. Many consonant sounds have several letters; the letters have traditional names such as "ko kai" (k, chicken), which are shown below.

How this chart was made: the letters and their names are read from the Unicode Character Database (version 16.0.0), so they are not typed by hand. For this script the label is the usual Latin spelling of the letter's sound as it appears in its Unicode name. The sound labels are approximate and no native reader has checked this page.

How to learn it

  1. Learn the consonant names: each name is a letter and a word that starts with it.
  2. Learn the tone marks last.
  3. Listen to a speaker: tones cannot be learned from a chart.

Questions

Why are there 44 consonants?

Thai kept letters for sounds that have merged, so several letters can stand for one sound. They differ in tone class.
