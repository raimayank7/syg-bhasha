Arabic: letters, names and quiz

28 symbols of the Arabic script (العربية), used for Arabic, and with extra letters Persian, Urdu and others.

The Arabic script is written from right to left. It is an abjad: it writes consonants, and short vowels are shown by marks that are usually left out. The chart shows the 28 basic letters.

Most letters join to the next letter, so each letter has up to four shapes (alone, at the start, in the middle, at the end). The chart shows each letter on its own. Six letters (ا د ذ ر ز و) join only to the letter before them. The Latin equivalent comes from the unidecode tables and is approximate.

How this chart was made: the letters and their names are read from the Unicode Character Database (version 16.0.0), so they are not typed by hand. The Latin equivalent comes from the transliterate or unidecode tables and is a guide only. The sound labels are approximate and no native reader has checked this page.

How to learn it

  1. Learn the letters in groups of similar shapes: ب ت ث, then ج ح خ.
  2. Learn the dots: they tell similar letters apart.
  3. Learn how letters join by writing short words.

Questions

Does Arabic have capital letters?

No. The script is the same size throughout.
