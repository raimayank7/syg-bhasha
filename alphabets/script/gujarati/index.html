Gujarati: letters, names and quiz

55 symbols of the Gujarati script (ગુજરાતી), used for Gujarati.

Gujarati is the script of the Gujarati language. It is written from left to right and looks like Devanagari without the line along the top. It is an abugida: Each consonant letter carries a built-in vowel (usually "a"). Other vowels are shown by signs written around the consonant, and a special sign (the virama or its equivalent) removes the vowel so that two consonants can join.

Because it has no top line, Gujarati letters were quick to write, and the script spread through the account books of traders in western India. The consonants follow the same order as Devanagari, so a reader of one can learn the other quickly.

How this chart was made: the letters and their names are read from the Unicode Character Database (version 16.0.0), so they are not typed by hand. For this script the label is the usual Latin spelling of the letter's sound as it appears in its Unicode name. The sound labels are approximate and no native reader has checked this page.

How to learn it

  1. Learn the vowel letters, then the consonants in rows.
  2. Compare each Gujarati letter with its Devanagari twin if you know Hindi.
  3. Practise the vowel signs with the letter ક.

Questions

Is Gujarati easier if I know Hindi?

Yes. The sounds, the order of the letters and the way letters combine are the same; only the shapes differ.
